\# Karnataka Crop Production Dataset



\## Dataset File



Indian\_crop\_production\_yield\_dataset.csv



\## Purpose



This dataset is used for the location-based agricultural analysis module of the AgriSmart project.



\## Columns



\- State\_Name

\- District\_Name

\- Crop\_Year

\- Season

\- Crop

\- Area

\- Production

\- yield



\## Karnataka Dataset Statistics



\- Records: 48,393

\- Years: 1997 to 2019

\- Crops: 61

\- Seasons: Kharif, Rabi, Summer, Whole Year

\- Missing values: None

\- Duplicate rows: None



\## Usage



The dataset supports:



\- District-wise crop analysis

\- Season-wise crop analysis

\- Historical production analysis

\- Crop yield comparison

\- Location-aware agricultural insights



\## Limitation



The dataset contains historical records only up to 2019.



No artificial data for 2020-2025 has been generated.



Future versions can integrate newer official agricultural datasets when reliably available.
